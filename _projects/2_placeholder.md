Front matter fields that matter:

| field         | effect                                                              |
| ------------- | ------------------------------------------------------------------- |
| `title`       | card heading                                                        |
| `description` | one line under the heading                                          |
| `img`         | card thumbnail; jpg, png or gif                                     |
| `importance`  | sort order within the category, ascending                           |
| `category`    | must match an entry of `display_categories` in `_pages/projects.md` |
| `redirect`    | optional; makes the card link straight to an external URL           |
